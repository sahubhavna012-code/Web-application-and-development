# Web Application & Development 🚀

Welcome to the **Web Application & Development** repository! This repository consolidates practice projects, code samples, exercises, and fundamental implementations across **HTML5**, **CSS3**, and **JavaScript**.

---

## 📂 Repository Structure

```
Web Application And Development/
├── HTML/                      # Core HTML5 elements, structures, and forms
│   ├── Basics/                # Headings, paragraphs, images, semantic tags
│   ├── Form/                  # Interactive HTML form controls and inputs
│   ├── List/                  # Ordered, unordered, and nested list layouts
│   ├── Table/                 # Data tables, cell merging (colspan/rowspan)
│   ├── iframe.html            # Inline frame embedding demo
│   └── resume.html            # Structured HTML personal resume page
│
├── CSS/                       # CSS styling, layouts, and design practice
│   ├── Box_Model.html         # CSS box model, margins, paddings, borders
│   ├── College.html & Clg_Style.css # Multi-section college website landing page
│   ├── Gym.html               # Fitness gym website design layout
│   ├── inline.html, internal.html, external.html # CSS insertion methods
│   ├── contact.html           # Styled contact form layout
│   └── *.css                  # Utility and theme stylesheets
│
└── JavaScript/                # Interactivity, DOM manipulation, and JS logic
    ├── 010_login.html         # User authentication & login form logic
    ├── 017_add.html           # Basic mathematical operations & input addition
    ├── 018_Age.html           # Conditional age verification logic
    ├── 019_Total_Marks.html   # Marks summation script
    └── 020_Percentage.html    # Academic percentage calculator
```

## 💻 Tech Stack & Features

- **HTML5**: Semantic tags (`<header>`, `<section>`, `<table>`, `<form>`), media embedding, document structures.
- **CSS3**: Selectors, Box Model, inline/internal/external styling techniques, custom layout designs.
- **JavaScript**: Fundamental scripts, user input handling, control flow, arithmetic calculations, and form validation.
