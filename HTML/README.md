# HTML5 & Web Development Fundamentals

A practice repository exploring HTML5 markup, semantic document structures, interactive forms, tables, and web page layouts.

---

## 📂 Repository Structure

```
├── Basics/                 # HTML elements, headings, tags, image embeds, links
├── Form/                   # Form inputs, labels, fieldsets, textareas, submit handlers
├── List/                   # Ordered, unordered, and nested list structures
├── Table/                  # Table layouts, borders, cell merging (colspan/rowspan)
├── iframe.html             # Inline frame embeds
└── resume.html             # Structured personal resume page built with pure HTML
```

---

## 🌐 Highlights
- **Semantic HTML5**: Usage of structural tags (`<header>`, `<section>`, `<table>`, `<form>`).
- **Form Controls**: Inputs, checkboxes, radio buttons, drop-down menus, and textareas.
- **Resume Page (`resume.html`)**: A complete clean personal resume template designed with semantic HTML tags.
